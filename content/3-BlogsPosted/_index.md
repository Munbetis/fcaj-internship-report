# AWS Knowledge Sharing Blogs

During my participation in the **First Cloud AI Journey (FCAJ)** internship program, I research and develop technical blog posts to summarize, reinforce, and share the knowledge I have gained about Amazon Web Services (AWS).

The blog posts focus on introducing AWS services, analyzing technical concepts, exploring system architectures, and demonstrating how technology can be applied to real-world problems.

In addition to theoretical content, the articles include practical examples, architecture diagrams, and knowledge related to the **Cloud Library Management System** project, helping connect AWS learning with real-world application development.

According to the FCAJ program requirements, each participant must complete at least **3 blog posts** and share them with the [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj) community.

Below are the three blog topics selected for research and development.

---

### [Blog 1: Amazon DynamoDB - Building a NoSQL Database on AWS](3.1-Blog1/)

**Topic:** Amazon DynamoDB and NoSQL databases.

**Main Content:**

- Introduction to Amazon DynamoDB and its key features.
- Understanding Tables, Items, Attributes, Partition Keys, and Sort Keys.
- Exploring CRUD operations and data retrieval methods.
- Learning how to integrate DynamoDB with AWS Lambda and Amazon API Gateway.
- Applying these concepts to book management, reader management, and borrowing and returning transactions in the Cloud Library project.

**Status:** Content in progress.

**Facebook Post:** To be added after publication.

---

### [Blog 2: AWS IAM - Identity Management and Access Security](3.2-Blog2/)

**Topic:** AWS Identity and Access Management (IAM).

**Main Content:**

- Introduction to AWS IAM and its role in securing AWS resources.
- Understanding the differences between IAM Users, Groups, Roles, and Policies.
- Exploring the Principle of Least Privilege.
- Learning about Multi-Factor Authentication (MFA).
- Demonstrating how to manage access permissions and protect resources in an AWS environment.

**Status:** Planned.

**Facebook Post:** To be added after publication.

---

### [Blog 3: Amazon Bedrock Knowledge Bases - Building an AI Assistant with RAG](3.3-Blog3/)

**Topic:** Amazon Bedrock, Knowledge Bases, and Retrieval-Augmented Generation (RAG).

**Main Content:**

- Introduction to Amazon Bedrock and Amazon Bedrock Knowledge Bases.
- Understanding how Retrieval-Augmented Generation (RAG) works.
- Exploring how documents stored in Amazon S3 can be used as knowledge sources.
- Learning about the process of retrieving information and generating responses using AI models.
- Applying these concepts to the AI assistant for answering library regulation questions and finding books in the Cloud Library project.

**Status:** Planned.

**Facebook Post:** To be added after publication.

### Objectives

Through researching and sharing technical blog posts, I aim to achieve the following objectives:

- Reinforce my knowledge of AWS services learned during the internship program.

- Improve my ability to present technical knowledge clearly and systematically.
- Enhance my skills in creating architecture diagrams and using visual illustrations.
- Connect AWS knowledge with real-world problems in the Cloud Library Management System project.
- Share knowledge and exchange experiences with the AWS Study Group community.
