### Week 3 Objectives:

* Learn the fundamentals of Networking in AWS and Amazon Virtual Private Cloud (VPC).
* Understand the basic components of a VPC, such as CIDR Blocks, IP Addresses, Subnets, and Route Tables.
* Learn about network security mechanisms using Security Groups and Network ACLs.
* Study how Internet Gateways and NAT Gateways work.
* Learn about Multi-tier Network Architecture in AWS.

### Week 3 Achievements:

* Gained foundational knowledge of **Amazon Virtual Private Cloud (VPC)**:
  * Understood the role of VPC in building a private network environment on AWS.
  * Learned about CIDR Blocks, IP Addresses, Regions, and Availability Zones.
  * Understood how Subnets are used to divide networks within a VPC.

* Understood how to organize and route networks in **Amazon VPC**:
  * Distinguished between Public Subnets and Private Subnets.
  * Understood the role of Route Tables.
  * Learned how network traffic is routed between Subnets.

* Gained basic knowledge of **Security Groups and Network ACLs (NACLs)**:
  * Understood how to use Inbound Rules and Outbound Rules.
  * Distinguished between the Stateful behavior of Security Groups and the Stateless behavior of NACLs.
  * Understood the role of these components in protecting AWS resources.

* Learned about Internet connectivity in a VPC environment:
  * Understood the function of an Internet Gateway.
  * Understood the role of a NAT Gateway for Private Subnets.
  * Understood how to combine Gateways and Route Tables to organize network traffic.

* Gained an overview of **Multi-tier Network Architecture**:
  * Understood the model of dividing a system into Web, Application, and Database tiers.
  * Learned how to combine network components to improve manageability and security.
  * Studied the process of deploying a multi-tier network architecture on AWS.

* Completed the summary and review of Networking knowledge during the week, establishing a foundation for upcoming AWS hands-on activities.
